# QPet Companion（Q宠后台伴侣）

QPet Companion 是一款基于 Kotlin 与 LSPosed 框架开发的手机 QQ 宠物辅助管理模块。本项目在手机 QQ 设置页面内提供二级管理界面，支持宠物状态展示、日夜间主题自适应、学园与职业小镇状态同步以及日常培养任务辅助管理。

## 功能特性

### 1. 设置页原生集成与日夜间主题自适应
- **二级设置界面**：集成于手机 QQ「设置」列表，采用分组卡片式纯文本排版，支持物理返回键平滑退出与触觉反馈。
- **日间/夜间模式同步**：自动检测手机 QQ 当前的日间或夜间主题状态，动态切换明亮模式（Light Mode）与深色模式（Dark Mode）界面配色及状态栏样式。

### 2. 学园课程与职业场所动态同步
- **学园阶段识别**：实时读取当前账号的学园阶段（初级、中级、高级、进修）、毕业状态与力量、智力、魅力三项属性值，支持按阶段、科目与课时偏好配置。
- **职业小镇全量场所识别**：动态同步职业小镇全部工作场所名称与解锁状态（含已解锁专属场所与未解锁隐藏职业），支持横向滑动选择与工时档位配置。
- **未解锁项防呆提示**：对于已毕业学园或尚未解锁的职业场所，界面自动置灰并拦截无效选择。

### 3. 日常照料阈值与任务协调
- **体力与清洁度阈值管理**：支持自定义进食体力阈值与洗澡清洁度阈值（低于 40 / 60 / 80 / 90），在数值低于设定阈值时触发日常照料与基础补给管理。
- **疲惫减益保护与自动转冒险**：实时检测学习与打工过程中的疲惫减益状态，触发时自动提前召回并转入森林探险，待疲惫 Buff 刷新后自动恢复常规任务。
- **好友福袋自动拆领**：周期性扫描好友列表中可拆领的福袋金币并自动完成拆取。
- **互斥任务协调**：内置学习、打工、历练三类外出任务的状态协调逻辑，根据当前任务剩余倒计时自动安排后续队列。
- **访客记录与回访互动**：支持查询近期到访记录并完成回访互动。

### 4. 手动即时指令与防误触确认
- **即时操作面板**：提供状态刷新、日常照料、派遣打工、启程学习、野外历练、收益结算、访客回访及召回宠物等手动操作入口。
- **二次确认机制**：点击任意手动即时指令时均弹出确认对话框，对中断当前任务的召回操作提供醒目警示，防止误触。

## 环境要求与安装说明

### 1. 运行环境
- Android 8.0（API 26）及以上系统
- 已安装并启用 LSPosed 框架（API 82+）
- 手机 QQ（`com.tencent.mobileqq`）

### 2. 安装与启用步骤
1. 前往 [Releases](https://github.com/congsmile/qpet-companion/releases) 页面下载最新版本的 APK 安装包。
2. 在 **LSPosed 管理器** 中启用 **Q宠后台伴侣** 模块，并勾选推荐作用域 **QQ (`com.tencent.mobileqq`)**。
3. 重启手机 QQ 后，进入「左上角头像 -> 设置 -> Q宠后台伴侣」即可打开配置界面。

> **版本升级提示**：自 `1.0.31` 版本起，模块应用包名更新为 `io.github.congsmile.qqpet`。若从早期旧包名版本升级，请先卸载旧版本后再安装新版本，并在 LSPosed 管理器中重新勾选作用域。

## 编译与构建

本项目采用标准的 Android Gradle（Kotlin DSL）构建流程：

```bash
git clone https://github.com/congsmile/qpet-companion.git
cd qpet-companion
./gradlew assembleDebug
```

编译完成后，构建产物位于 `app/build/outputs/apk/debug/app-debug.apk`。
