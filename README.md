> **全新一代 QQ 宠物后台全能自动化伴侣 (LSPosed 模块)**  
> 纯原生 Kotlin 构建，深度内嵌手机 QQ 设置，全套官方底层协议闭环，免抓包、零风控、纯文本美学排版与物理弹簧交互。

## 🌟 为什么完全不同？

本项目与市面上既有的 PC 模拟、Selenium 网页挂机或传统外部抓包脚本有着本质上的代际区别：

- **深度进程内嵌**：直接驻留在手机 QQ 主进程内部，无缝植入 QQ 原生「设置」菜单，无需单独打开第三方应用，手机在后台即可静默全自动调度。
- **宿主原生 SSO / OIDB 信道**：通过 LSPosed 动态拦截并复用手机 QQ 官方的 `PetPbDelegate` 通信层，直接借道 QQ 现有的安全长连接，**不提取、不落盘、不维护任何 Skey / Cookie / Token**，与官方交互行为完全同源，真正做到零风控。
- **全套官方业务协议闭环逆向**：完全抛弃脆弱的前台点击模拟与静态硬编码，所有学园课程、打工工种、访客互动均基于底层二进制 ProtoWire 与 OIDB 服务码动态解析驱动。

## ✨ 核心特性

### 1. 原生协议级桥接与安全通信
- 直接挂载 QQ 宿主发包接口，依托宿主会话下发 OIDB 业务包，消除所有第三方网络代理与登录态失效风险。

### 2. QQ 原生沉浸式二级页面与 Apple Design 纯文本美学
- **原生转场与层级设计**：在 QQ 设置中提供如原生页面般的全屏沉浸式二级交互，顶部配备 Navigation Bar（返回箭头、居中标题、运行状态胶囊），支持右滑与物理返回键平滑退场。
- **无图极简排版（Apple Typography）**：全面摒弃杂乱的彩色图标与 Emoji 装饰，完全依仗字重对比、舒适行间距与 Inset Grouped 分组卡片构建呼吸感与高档质感。
- **物理弹簧微动效（Response: Kill Latency）**：所有选项与按钮均配备按下瞬间缩放（`scale(0.97)`）与震动触觉反馈；子设置展开与折叠具备 Interruptible Spring 平滑过渡。

### 3. 动态嗅探与智能防呆防错
- **学园阶段与资质透视**：率先解析官方协议回包中的学园阶段、毕业标识（`isGraduated`）与属性值（力量/智力/魅力）。
- **打工工种岗位探查**：实时向官方拉取演艺、文职、搬运对应岗位的真实解锁状态与时长档位（10分钟/45分钟/2小时/4小时）。
- **iOS 级交互置灰与拦截**：已毕业或未解锁的选项动态置灰不可选（透明度 0.38f）；误触立即弹出原生 Toast 指引原因，杜绝盲目配置导致的协议报错。

### 4. 全自动化智能生命周期轮转
- **外出互斥动作调度**：外出上学、打工赚钱、野外冒险三者互斥，内置智能优先级队列与冲突防呆，支持单项专精或多维轮替。
- **倒计时休眠机制**：根据服务端下发的倒计时秒数精确挂起协程，到期自动唤醒并发起收益结算，零多余功耗。
- **生命体征监控**：自动检测饱腹度与清洁度，周期性触发自动喂食与洗澡保养指令。

### 5. 访客「自动回踩」与互动闭环（类似空间互赞）
- **来访记录精准拉取**：CMD `39006` (`0x985e_0`) 动态获取谁来踩过我家宠物，支持解析访客 UIN、昵称与是否需要回踩状态。
- **全自动常驻回踩**：在后台巡检中每 5 分钟自动批处理回踩未互动的好友（CMD `39003` / `0x985b_0`），支持在「日常起居与历练」中随时一键独立启闭。

## 🛠️ 快速安装与使用

### 1. 环境准备
- 已 Root 设备（Magisk / KernelSU / APatch）
- 已安装并启用 [LSPosed](https://github.com/mywalkb/LSPosed_mod) 框架环境（Zygisk 版）
- 官方最新或主流版本手机 QQ（`com.tencent.mobileqq`）

### 2. 安装与激活
1. 前往 [Releases 发布页面](https://github.com/congsmile/qpet-companion/releases) 下载最新的 `app-v1.0.30-debug.apk`。
2. 打开 **LSPosed Manager**：
   - 在模块列表中找到 **Q宠后台伴侣**。
   - 开启模块，推荐作用域已默认勾选 **QQ (`com.tencent.mobileqq`)**。
3. 强行停止或重启手机 QQ 使 Hook 规则生效。

### 3. 打开使用
1. 打开手机 QQ，点击左上角头像 -> 底部「设置」。
2. 在设置列表中点击 **「Q宠后台伴侣」** 进入全屏二级设置页。
3. 自选学园、打工或日常项目，模块即刻在后台开始全自动接管。
